- 휴대폰 크기에서는 앞·뒤 선택과 별도 듣기, 좁히기, 보관 후 상위 이동, 취소, 재개가 모두 터치 버튼으로 가능하다. 저장 후 오류는 시간축과 교정 대기에 나타난다
- `make lint`, Rust 시험 83건, Chrome 화면 시험 18건을 통과했다. 화면 시험은 390px 터치 모드의 두 갈래 저장과 동일 요청 재시도, 첫 실행에서 입력 시작, 원본과 초안 표시, 확정 후 다음 조각 잠금, 다운로드 안내의 이미지와 빌드 링크를 확인했다. 사이트는 로컬에서 열어 확인했고, 모바일 설치본 실기기 시험은 남았다
